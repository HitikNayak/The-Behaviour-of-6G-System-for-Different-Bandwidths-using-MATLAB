# The-Behaviour-of-6G-System-for-Different-Bandwidths-using-MATLAB

# Shannon Capacity MATLAB Project

## Objective
To analyze the variation of Shannon Channel Capacity with Signal-to-Noise Ratio (SNR) for different bandwidths.

## Formula

C = B log2(1 + SNR)

Where:
- C = Channel Capacity (bps)
- B = Bandwidth (Hz)
- SNR = Signal-to-Noise Ratio

## Bandwidths Used
- 20 kHz
- 25 kHz
- 30 kHz

## Software
- MATLAB

## Output

The graph shows Shannon Capacity increasing with:
1. Increasing SNR
2. Increasing Bandwidth
